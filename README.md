## 🚀 Layihə Haqqında

**Guardian-X** – kənd təsərrüfatında zərərvericilərlə mübarizəni tamamilə avtomatlaşdıran, əlçatan, çoxdilli və ekoloji təmiz bir sistemdir. Bu sistem yalnız zərərvericiləri aşkar etmir, həm də süni intellekt vasitəsilə onları tanıyır, real vaxt rejimində xəbərdarlıqlar göndərir və dərmanlama cədvəlini optimallaşdırır.

Xaçmaz bölgəsinin zəngin kənd təsərrüfatı təcrübəsindən ilhamlanan komandamız, yerli fermerlərin qarşılaşdığı çətinlikləri texnologiya ilə həll etməyi hədəfləyir.

## ✨ Əsas Xüsusiyyətlər

- **🔍 Süni İntellektlə Zərərverici Aşkarlanması:** Raspberry Pi Zero 2 W və yüksək keyfiyyətli kameralar vasitəsilə aphids (mənənələr), codling moths (alma qurdu) və böcəklərin 24/7 monitorinqi.
- **📱 Çoxkanallı Xəbərdarlıq Sistemi:** Pestisid təhlükəsi yarandıqda həm mobil tətbiq, həm də SMS (Bakcell, Nar, Azercell) vasitəsilə ani bildirişlər.
- **📅 Avtomatlaşdırılmış Müalicə Cədvəli:** Hər növ bitki üçün xüsusi lokallaşdırılmış dərmanlama təqvimi və süni intellekt əsaslı tövsiyələr.
- **☀️ Müstəqil Enerji Təminatı:** Günəş panelləri ilə işləyən modulyar detektorlar.
- **🌍 Çoxdilli Dəstək:** Azərbaycan, İngilis və Rus dillərində tam interfeys.

## 🛠️ Texnoloji Stack

Guardian-X müasir həm aparat (hardware), həm də proqram (software) texnologiyalarının sintezidir:

### **Frontend & Web**
- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Styling:** Tailwind CSS & Lucide Icons
- **3D Visualization:** React Three Fiber & Three.js (Detektorun 3D modeli üçün)
- **State Management:** React Hooks & Context API

### **Hardware & Embedded**
- **Computer:** Raspberry Pi Zero 2 W
- **Optics:** High-Res Wide Lens Camera
- **Sensing:** Modular Altitude Detectors
- **Power:** Solar Energy Panels

### **Intelligence & Backend**
- **AI Models:** Computer Vision (Pest Presence & Severity Analysis)
- **Communication:** SMS Gateway Integration (Local Carriers)

## ⚙️ Sistem Necə İşləyir?

1.  **Monitorinq:** Sahənin müxtəlif hündürlüklərində quraşdırılmış detektorlar ətraf mühiti izləyir.
2.  **Analiz:** Çəkilmiş şəkillər yerli (onboard) süni intellekt tərəfindən emal edilir.
3.  **Təsnifat:** Zərərvericinin növü və yayılma intensivliyi müəyyən edilir.
4.  **Böyük Məlumat:** Analiz nəticələri bulud sisteminə ötürülür və fermerə tövsiyə hazırlanıb göndərilir:
    > "Detector #2: 25% mənənə infeksiyası aşkarlandı. Confidor Extra ilə dərmanlama tövsiyə olunur."

## 🏆 Müvəffəqiyyətlərimiz və Mərhələlər

- **Zəngilan AI in Agriculture Bootcamp:** Zəngilanda keçirilən butkampda iştirak edərək ekspertlərlə əlaqələr qurulmuş və sistem yeni regionlarda sınaqdan keçirilmişdir.
- **Xaçmaz Regionunda Real Sınaqlar:** Sistem Xaçmazın müxtəlif kənd təsərrüfatı sahələrində real şəraitdə manual qiymətləndirmədən keçmişdir.
- **Fermer Rəyləri:** Yerli fermerlər tərəfindən yüksək qiymətləndirilmiş və onların ehtiyaclarına uyğun olaraq daimi təkmilləşdirilir.
- **Kənd Təsərrüfatı Seminarları:** Guardian-X pilot ərazilərdə təqdim olunmuş və müsbət rəylər alınmışdır.
